# Session Resume Dashboard ⚡

![Dashboard Preview](preview.jpg)

A lightweight, futuristic dashboard designed to manage and instantly resume your AI agent workflows (like Antigravity, Claude Code, Codex, and OpenCode) across multiple terminals.

## 🚀 Features
- **One-Click Resume**: Instantly boots a closed terminal session right where you left off.
- **Auto-Startup**: Designed to run automatically on system boot via Task Scheduler.
- **Live Play Log**: See real-time execution logs for all active proxies and agents.
- **Built for AI Workflows**: Natively supports multiple CLI environments and local proxy states.

## ⚙️ Installation & Usage
1. Clone the repository.
2. Ensure you have `fastapi` and `uvicorn` installed:
   ```bash
   pip install fastapi uvicorn
   ```
3. Run the dashboard:
   ```bash
   python resume_dashboard.py
   ```
4. Access the UI at **http://localhost:8765**
